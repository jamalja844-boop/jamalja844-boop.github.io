# Overzicht externe kosten

Noblenest zelf heeft geen abonnement of licentiekosten. Je betaalt alleen voor de diensten die je zelf kiest. Bedragen zijn indicatief; controleer altijd de actuele prijzen bij de aanbieder.

| Dienst | Nodig? | Indicatie | Opmerking |
|---|---|---|---|
| Shopify-abonnement | Ja (je winkel) | Volgens je huidige Shopify-plan | Eigen apps (custom distribution) zijn zonder extra Shopify-kosten |
| Shopify Dev Dashboard + ontwikkelwinkel | Ja, om te testen | Gratis | |
| Hosting van de app | Ja, voor productie | Ca. € 5–25 per maand | Kleine container is voldoende voor één winkel |
| PostgreSQL (beheerd) | Ja | Ca. € 0–25 per maand | Gratis niveaus bestaan bij sommige aanbieders; let op back-ups |
| Redis (beheerd) | Vanaf fase 6 | Ca. € 0–10 per maand | |
| Claude API (Anthropic) of OpenAI API | Optioneel (AI Studio) | Per gebruik (per token) | Kosten hangen af van model en aantal producten; je gebruikt je eigen sleutel |
| AliExpress Open Platform / Alibaba API | Optioneel | Toegang zelf gratis of op aanvraag; voorwaarden van de leverancier | Vereist goedkeuring |
| ECB-wisselkoersen | Ja (automatisch) | Gratis | |
| Domeinnaam + HTTPS | Aanbevolen | Ca. € 10 per jaar; certificaat meestal gratis | |

Noblenest schakelt nooit zelf betaalde diensten in. AI-functies en leverancierskoppelingen werken pas nadat jij een eigen sleutel invoert.
