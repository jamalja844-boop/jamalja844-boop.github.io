== Description ==

Nederlandstalig dashboard voor Clean Schoonmaakbedrijf B.V. Zie README.md voor de volledige handleiding, configuratie en het overzicht van vereiste API-toegang.

* Werkt samen met Rank Math, Yoast, AIOSEO en SEOPress (geen dubbele metadata, sitemaps of schema).
* Google Ads uitsluitend alleen-lezen; nooit automatische wijzigingen.
* AI-voorstellen (Claude) worden pas na expliciete goedkeuring toegepast; tekstherschrijvingen als concept.
* Cookieloze, AVG-vriendelijke leadmeting; respecteert Google Consent Mode en de WP Consent API.

== Installation ==

1. Plugins → Nieuwe plugin → Plugin uploaden → clean-seo-ads-ai-manager.zip.
2. Activeren en naar "Clean SEO & Ads AI → Instellingen".
3. Zet sleutels bij voorkeur als constanten in wp-config.php (zie README.md).
